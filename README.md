# قطعه‌رسان — وب‌سایت

وب‌سایت عمومی برند **قطعه‌رسان** (GhatehResan) — سامانهٔ تأمین و فروش قطعات یدکی خودرو.
فارسی، راست‌چین (RTL)، استاتیک و مطابق با کتاب برند نسخهٔ ۱٫۰.

> شعار: **قطعه‌ات رو می‌رسونیم**

## ساختار پروژه

```
build.mjs               استاتیک‌ساز صفحات (بدون وابستگی)
src/
  input.css             دیزاین‌سیستم (Tailwind 4 + توکن‌های رسمی برند)
  partials/             قالب‌های مشترک (head، header، footer، جست‌وجو، آیکون‌ها)
  pages/                هر صفحه = یک HTML + یک JSON برای متادیتای SEO
public/                 خروجی آمادهٔ میزبانی (خروجی build)
  assets/css/app.css    CSS ساخته‌شده با Tailwind
  assets/fonts/         وزیرمتن (OFL) و Inter — خودمیزبان، بدون CDN
  assets/images/        لوگوهای رسمی برند + og-cover
  assets/js/
    config.js           پیکربندی زمان اجرا (تلفن/ایمیل/اندپوینت‌ها) — بدون بازسازی
    catalog-data.js     دادهٔ نمایشی کاتالوگ (هم‌ساختار با جدول products سامانهٔ مدیریت)
    site.js             جست‌وجو، کاتالوگ، صفحهٔ محصول، فرم‌ها، وضعیت‌ها
docs/                   استقرار، اتصال به سامانهٔ مدیریت و یادداشت‌های راه‌اندازی
```

## اجرا و ساخت

```bash
npm install
npm run build          # ساخت صفحات + CSS مینیمم‌شده در public/
npm run build:pages    # فقط صفحات (سریع، هنگام ویرایش محتوا)
npm run dev:css        # watch روی CSS
npm run serve          # پیش‌نمایش محلی روی http://localhost:8000
```

خروجی `public/` کاملاً استاتیک است و روی هر میزبان استاتیکی (نگینکس، GitHub Pages،
هاست اشتراکی، CDN) قابل انتشار است. جزئیات در `docs/DEPLOYMENT.md`.

## منابع حقیقت

| موضوع | منبع |
|---|---|
| هویت بصری، رنگ، تایپوگرافی، لحن | کتاب برند (`brand-ghatehresan`) — بخش‌های ۰۳ تا ۰۸ |
| دسته‌بندی‌ها و خودروها | جدول‌های `categories` و `vehicles` در سامانهٔ مدیریت |
| ساختار فیلدهای محصول | جدول `products` سامانهٔ مدیریت (فقط فیلدهای عمومی) |

دادهٔ فعلی کاتالوگ **نمایشی** است (نمونه‌های خود کتاب برند) و با اتصال به API واقعی،
`catalog-data.js` جای خود را به دادهٔ سرور می‌دهد — بدون تغییر رابط کاربری.
راهنمای اتصال امن در `docs/INTEGRATION.md`.

## پیکربندی پیش از راه‌اندازی

همهٔ موارد «هنوز راه‌اندازی نشده» در `public/assets/js/config.js` است:
تلفن، ایمیل، نشانی، پیوند شبکه‌ها و آدرس API فرم‌ها. تا وقتی مقدارها `null` باشند،
سایت به‌جای نمایش اطلاعات جعلی، متن صادقانهٔ «پس از راه‌اندازی» نشان می‌دهد و فرم‌ها
حالت «متصل به سرور نیست» را مدیریت می‌کنند.

مواردی که قبل از انتشار واقعی باید تأیید/تنظیم شوند در `docs/LAUNCH-CHECKLIST.md` فهرست شده‌اند
(دامنه، وعده‌های عملیاتی ارسال/مرجوعی، متن‌های حقوقی).

## اصول پیاده‌سازی

- **برند:** سرمه‌ای `#0E2A47` (۳۰٪)، خنثی (۶۰٪)، نارنجی `#F26B1D` حداکثر ۱۰٪ و فقط برای کنش؛
  وزیرمتن ۴۰۰/۵۰۰/۷۰۰/۹۰۰ + اینتر ۶۰۰ برای اعداد فنی؛ برچسب وضعیت با گوشهٔ ۵px.
- **صداقت داده:** موجودی/قیمت/زمان تحویل هرگز جعلی نمایش داده نمی‌شود؛
  وضعیت‌ها `موجود / موجودی کم (با تعداد) / ناموجود / قابل سفارش (با زمان)` هستند.
- **بدون Backend جعلی:** فرم‌ها فقط به اندپوینت‌های تعریف‌شده در `config.js` ارسال می‌شوند؛
  در غیر این صورت خطای صادقانه نشان می‌دهند.
- **دسترس‌پذیری:** `lang="fa" dir="rtl"`، لینک پرش، فوکوس قابل‌دید، کنتراست AA به بالا،
  بزرگ‌نمایی کاربر محدود نشده است.
- **SEO:** عنوان/توضیح یکتا برای هر صفحه، canonical، Open Graph، JSON-LD
  (Organization، WebSite+SearchAction، FAQPage، Product)، sitemap و robots.

## مجوزها

- وزیرمتن: SIL OFL (فایل لایسنس همراه فونت‌ها)
- Inter: SIL OFL
- لوگو و هویت بصری: متعلق به برند قطعه‌رسان
