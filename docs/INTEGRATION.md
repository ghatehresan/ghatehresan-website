# اتصال به سامانهٔ مدیریت (بدون شکستن امنیت)

سامانهٔ مدیریت قطعه‌رسان یک ابزار داخلی PHP/SQLite است: **بدون Login، بدون REST API**.
بنابراین وب‌سایت هرگز نباید مستقیم به دیتابیس یا صفحات آن وصل شود.

## خط قرمزها

- ❌ اتصال مرورگر/سرور سایت به SQLite یا MySQL سامانهٔ مدیریت
- ❌ iframe یا fetch روی صفحات PHP مدیریت (هر بازدیدکننده‌ای ادمین می‌شود)
- ❌ انتشار Backup/CSV روی مسیر عمومی
- ❌ نمایش فیلدهای خصوصی: `buy_price`، `supplier_id`، `notes`

## الگوی پیشنهادی: «Projection عمومی» + همگام‌سازی یک‌طرفه

```
سامانهٔ مدیریت (محلی/شبکهٔ داخلی)
        │  ۱. اسکریپت Export (فقط فیلدهای مجاز)
        ▼
   catalog.json / یا API فقط‌خواندنی
        │  ۲. fetch در BFF یا build
        ▼
   وب‌سایت عمومی
```

### فهرست سفید فیلدهای عمومی (از جدول products)

| فیلد مدیریت | نام در سایت | توضیح |
|---|---|---|
| part_number | partNumber | همیشه لاتین نمایش داده شود |
| name | name | |
| category_id | category | با نگاشت به نام دسته |
| brand / quality | brand / quality | |
| sell_price | price | فقط قیمت فروش، نه خرید |
| stock_qty | status + stockNote | عدد خام منتشر نشود؛ فقط وضعیت و در حالت «کم»، تعداد |
| lead_days | leadDays | برای «قابل سفارش» |
| year_engine | specs | اختیاری |

خودروهای سازگار از جدول `product_vehicles` + `vehicles`؛
دسته‌ها از `categories`.

### انتشار وضعیت موجودی

طبق لحن برند، «موجودی واقعی» یعنی:

- `stock_qty > 5` → «موجود در انبار»
- `1 <= stock_qty <= 5` → «موجودی کم · N عدد باقی»
- `stock_qty = 0 && lead_days > 0` → «قابل سفارش · تحویل حدود N روز کاری»
- `stock_qty = 0 && lead_days = 0` → «ناموجود»

(آستانه‌ها قابل تنظیم در اسکریپت Sync است؛ عدد خام هرگز به مرورگر نرود.)

### گزینه‌های اجرایی

| گزینه | چه زمانی | پیچیدگی |
|---|---|---|
| A. اسکریپت Export زمان‌بندی‌شده روی ماشین مدیریت → `catalog.json` → سایت آن را fetch می‌کند | سامانه محلی می‌ماند | کم |
| B. سرویس میانجی (BFF) با Authentication و Cache | نیاز به دادهٔ لحظه‌ای | متوسط |
| C. افزودن API فقط‌خواندنی + توکن به خود سامانهٔ مدیریت، پشت VPN/کلادفلر | بلندمدت | زیاد — نیازمند بازنگری امنیت سامانه |

در همهٔ گزینه‌ها: خروجی با همان ساختار `window.GR_CATALOG` هم‌خوان نگه داشته شود تا
رابط کاربری بدون تغییر بماند.

## فرم‌ها

`config.js > endpoints` را به API امن (با اعتبارسنجی، محدودیت نرخ و ذخیرهٔ سمت سرور) وصل کنید.
بدون Backend، فرم‌ها حالت «متصل نیست» را صادقانه نمایش می‌دهند و هیچ داده‌ای جایی ارسال نمی‌شود.
